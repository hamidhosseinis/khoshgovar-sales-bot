# Khoshgovar Sales Bot | دستیار فروش خوشگوار

پروژه‌ای مستقل برای توسعه بات تلگرام ویژه مشتریان فروشگاهی؛ با هدف معرفی محصولات، نمایش **اطلاعات و طرح‌های فروش مجاز برای انتشار** و محاسبه قیمت خرید بر اساس قواعد تأییدشده.

> این پروژه یک ابزار مستقل است و انتشار کد آن به معنی تأیید یا وابستگی رسمی به شرکت نیست.

## قابلیت‌های موردنظر

- نمایش محصولات بر اساس خانواده کالایی و سپس مدل یا تنوع محصول.
- نمایش مشخصات و قیمت‌های قابل انتشار؛ اعلام قیمت‌ها **به‌ازای هر بطری**.
- نمایش طرح‌های عمومی فعال و محاسبه تخفیف بر اساس شرایط معتبر هر طرح.
- سبد خرید و پیشنهاد طرح مناسب‌تر، در صورت احراز شرایط.
- امکان ارتباط مشتری با بخش مشاوره.

فعال بودن هر قابلیت در محیط عملیاتی به تکمیل پیاده‌سازی، آزمون و تنظیم دسترسی‌ها وابسته است.

## معماری

- **Telegram Bot API:** رابط کاربری مشتریان.
- **Cloudflare Workers:** منطق بات، کنترل دسترسی و پردازش درخواست‌ها.
- **Google Sheets:** تنها مرجع رسمی داده‌های فروش؛ خواندن از منبع مجاز در سمت سرور انجام می‌شود.
- **Cloudflare D1:** نگهداری وضعیت اجرایی مانند سبد خرید، نه جایگزین داده‌های مرجع فروش.
- **GitHub Actions:** اجرای آزمون‌ها و بررسی تغییرات.

## امنیت و حریم اطلاعات تجاری

- اطلاعات تأییدنشده به‌صورت پیش‌فرض **محرمانه** هستند.
- فقط محصولات، قیمت‌ها و طرح‌های دارای مجوز انتشار و شرایط معتبر به مشتری نمایش داده می‌شوند.
- اطلاعات داخلی و عمومی از طریق قواعد سمت سرور تفکیک می‌شوند.
- توکن‌ها، کلیدهای سرویس و سایر اعتبارنامه‌ها تنها در سرویس مدیریت **Secrets** نگهداری می‌شوند؛ نه در کد یا مخزن.
- لینک و شناسه فایل‌های خصوصی و جزئیات دسترسی به منابع فروش در مستندات عمومی منتشر نمی‌شوند.
- در صورت اختلال در دسترسی به مرجع داده یا نامعتبر بودن اطلاعات، از منبع جایگزین استفاده نمی‌شود و داده‌ای بدون تأیید منتشر نخواهد شد.

## توسعه و آزمون

پروژه با JavaScript و Node.js توسعه داده می‌شود. برای اجرای آزمون‌ها:

```bash
npm test
```

تغییرات از طریق شاخه مجزا و **Pull Request** بررسی و سپس وارد شاخه اصلی می‌شوند.
