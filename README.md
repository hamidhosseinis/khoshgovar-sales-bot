# Khoshgovar Sales Bot | دستیار فروش خوشگوار

بات تلگرامی مستقل برای نمایش **اطلاعات عمومی و مجاز محصولات** و **طرح‌های فروش قابل انتشار** به مشتریان فروشگاهی و محاسبه قیمت بر پایه منابع تأییدشده.

> وضعیت بررسی‌شده ۶ نوامبر ۲۰۲۶: Webhook، موتور طرح‌ها، سبد D1، پیشنهاد ارتقا و خواندن امن Sheets کدنویسی و روی Cloudflare Worker بارگذاری شده‌اند؛ اما **بات تلگرام هنوز فعال نیست** چون Secrets تلگرام/حساب سرویس Google ثبت نشده‌اند و Telegram Webhook تنظیم نشده است. طرح‌های موجود نیز DRAFT و فاقد تاریخ اعتبارند.

## کاربران و دسترسی‌ها

- **مشتری فروشگاهی:** جست‌وجوی محصولات، مشاهده تصاویر و مشخصات عمومی، طرح‌های عمومی منتشرشده و قیمت‌های تأییدشده.
- **مدیر مجاز:** مدیریت انتشار محصولات و طرح‌ها، و دسترسی کنترل‌شده به اطلاعات داخلی مطابق مجوز.
- **پیش‌فرض امن:** محتوای تأییدنشده محرمانه در نظر گرفته می‌شود؛ مجوزها در سمت سرور اعمال می‌شوند، نه صرفاً با مخفی کردن دکمه‌ها.

## معماری پیاده‌سازی‌شده (در انتظار اتصال Secrets)

Telegram Bot ↔ Cloudflare Worker ↔ نسخه خصوصی Google Sheets (read-only) و Cloudflare D1 (سبد خرید)

نسخه خصوصی Sheets: https://docs.google.com/spreadsheets/d/1M0cRg-tDXA2bZimx9o8Cr6C5QmQi-tg1HLtcFNRkwWo/edit

شیت اولیه و پوشه اصلی عمومیِ قابل ویرایش‌اند و از آن‌ها برای خواندن زنده مشتریان استفاده نمی‌شود.

GitHub (private) → نگهداری کد، بازبینی تغییرات و انتشار کنترل‌شده.

## اصول پروژه

- مستقل از پروژه‌های دیگر؛ بدون کپی کردن رمز، توکن یا داده محرمانه.
- حداقل هزینه و استفاده از سرویس‌های رایگان تا زمان تأیید مالک.
- قیمت و طرح بدون تأیید اعتبار منبع منتشر نشود.
- بارگذاری تصاویر محصولات صرفاً با حق استفاده مناسب.
- این پروژه شخصی است و به‌تنهایی نماینده تأیید یا وابستگی رسمی شرکت نیست.

## موارد لازم برای فعال‌سازی مشتریان

1. مالک، TELEGRAM_BOT_TOKEN چرخش‌یافته و TELEGRAM_WEBHOOK_SECRET را مستقیماً در Secrets همان Worker ثبت کند؛ هیچ‌یک در گفتگو/GitHub ارسال نشوند.
2. مالک Google Sheets API را فعال کرده و Service Account فقط-خواندنی را به شیت خصوصی Viewer بدهد؛ GOOGLE_SERVICE_ACCOUNT_JSON را در Cloudflare Secret ثبت کند.
3. پس از تأیید فنی و صحت تنظیمات، Telegram setWebhook با آدرس عمومی Worker و Secret ثبت شود.
4. محصولات را فقط با دسته‌بندی تأییدشده و طرح‌ها را پس از تأیید مجوز و تاریخ اعتبار منتشر کنید؛ برای قیمت نهایی، مبنای قیمت و مالیات و گردکردن مصوب لازم است.
5. تصاویر به درخواست مالک در این مرحله غیرفعال‌اند.
