# Khoshgovar Sales Bot | دستیار فروش خوشگوار

بات تلگرامی مستقل برای نمایش **اطلاعات عمومی و مجاز محصولات** و **طرح‌های فروش قابل انتشار** به مشتریان فروشگاهی و محاسبه قیمت بر پایه منابع تأییدشده.

> ⚠️ وضعیت فعلی: مرحله طراحی و آماده‌سازی. بات هنوز در این مخزن پیاده‌سازی یا به تلگرام متصل نشده است.

## کاربران و دسترسی‌ها

- **مشتری فروشگاهی:** جست‌وجوی محصولات، مشاهده تصاویر و مشخصات عمومی، طرح‌های عمومی منتشرشده و قیمت‌های تأییدشده.
- **مدیر مجاز:** مدیریت انتشار محصولات و طرح‌ها، و دسترسی کنترل‌شده به اطلاعات داخلی مطابق مجوز.
- **پیش‌فرض امن:** محتوای تأییدنشده محرمانه در نظر گرفته می‌شود؛ مجوزها در سمت سرور اعمال می‌شوند، نه صرفاً با مخفی کردن دکمه‌ها.

## معماری پیشنهادی (هنوز پیاده‌سازی نشده)

Telegram Bot ↔ Cloudflare Worker ↔ منابع داده تأییدشده (Google Sheets و/یا Supabase)

GitHub (private) → نگهداری کد، بازبینی تغییرات و انتشار کنترل‌شده.

## اصول پروژه

- مستقل از پروژه‌های دیگر؛ بدون کپی کردن رمز، توکن یا داده محرمانه.
- حداقل هزینه و استفاده از سرویس‌های رایگان تا زمان تأیید مالک.
- قیمت و طرح بدون تأیید اعتبار منبع منتشر نشود.
- بارگذاری تصاویر محصولات صرفاً با حق استفاده مناسب.
- این پروژه شخصی است و به‌تنهایی نماینده تأیید یا وابستگی رسمی شرکت نیست.

## مراحل آینده

1. ثبت BotFather، تنظیم پروژه ChatGPT و تعیین مجوزهای انتشار.
2. پیاده‌سازی امن Webhook، احراز هویت مدیر و منوی عمومی.
3. افزودن کاتالوگ و تصاویر تأییدشده.
4. اتصال منبع قیمت‌ها و تست محاسبه طرح‌های عمومی.
5. آزمون امنیت و انتشار تدریجی.
